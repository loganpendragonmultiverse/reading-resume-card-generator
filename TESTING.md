# Testing

Run `ruff format --check .`, `ruff check .`, `mypy src`, `pytest`, and `python -m build`. CI also audits dependencies and runs the supported OS/Python matrix.

## 1.2.0 regression acceptance

Run the complete existing suite plus the new regression fixtures. Confirm the documented command produces the selected output, malformed input remains actionable, and source files remain unchanged. Validate nested checkpoint records and add printable pocket/phone cards with checkpoint previews and hidden-item counts.

Resolution fixtures cover before/on/after boundaries, chronology, export ceilings,
unsupported spoiler canaries, previous-checkpoint deltas and legacy status.

Gold regression fixtures cover malformed records, preserved sources, and exclusive output creation. Run the full suite and install both wheel and source distribution in fresh environments before release.

Existing output symbolic links are refused explicitly on Windows as well as POSIX. Output directories should remain under your control while a command runs.

Wheels install README, development, testing and changelog guides at `share/reading-resume-card-generator/` under the Python environment, with editable examples in its `examples/` subdirectory. Both release distributions must contain these exact tagged files.
